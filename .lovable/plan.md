# Datacrest signature portal

## Experience
- Replace the placeholder home page with a responsive signature generator inspired by the supplied CEO signature and reference site.
- Use Datacrest’s forest-green, white, and copper-gold identity, with an editable employee detail form alongside a live email-signature preview.
- Start with the supplied CEO details and let users personalize name, title, department, email, phone, website, and address.
- Provide one-click copy of email-safe HTML and an HTML download.

## Technical details
- Keep the editable signature model and email-compatible HTML generator in a shared utility so preview, clipboard, and download remain aligned.
- Use the uploaded Datacrest banner as a hosted asset, semantic CSS design tokens, existing form/button components, and page-specific metadata.
- No accounts or server-side storage are needed for this self-contained editor.

## Verification
- Check that the page builds, the live preview responds to edited fields, copy/download actions work, and the layout remains usable at desktop and mobile widths.
